# assets/icons/

Pasta reservada para ícones de tecnologias (HTML5, CSS3, JavaScript, PHP, MySQL, etc.),
caso queiras adicionar logótipos de stack técnica no futuro.

Não incluí nenhum aqui de propósito: o Brand Kit oficial não fornece estes ícones
(não fazem parte da tua identidade visual pessoal), e o prompt pede para não inventar
ou aproximar ícones quando não há um asset oficial correspondente. A secção de Skills
usa por isso etiquetas tipográficas (JetBrains Mono) em vez de logótipos de terceiros.

Se mais tarde quiseres adicionar ícones reais (ex. de https://simpleicons.org, que são
gratuitos e license-friendly para este uso), este é o sítio certo para os guardar.
