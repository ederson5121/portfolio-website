Portfólio pessoal de **Ederson Serafim Malanda**, estudante de Gestão de Sistemas Informáticos, residente em Luanda, Angola.

O projeto apresenta o meu percurso, competências, formação e interesses na área de tecnologia através de uma landing page moderna, responsiva e otimizada para funcionar sem dependências externas.

## Sobre o projeto

Este portfólio foi desenvolvido para apresentar a minha identidade profissional, conhecimentos técnicos e projetos de forma clara, acessível e visualmente consistente.

A versão V1.5 foi construída exclusivamente com:

- HTML5
- CSS3
- JavaScript puro

Não são utilizados frameworks, bibliotecas externas ou CDNs.

Toda a tipografia, iconografia e assets de marca são servidos localmente. Esta decisão foi intencional, considerando as condições de conectividade e desempenho em Angola.

---

##  Funcionalidades

- Layout responsivo para diferentes tamanhos de ecrã.
- Tema claro e escuro baseado em tokens semânticos.
- Menu mobile com suporte a teclado e `Escape`.
- Focus trap no painel de navegação mobile.
- Scroll suave entre secções.
- Deteção da secção ativa através de scrollspy.
- Animações de entrada com suporte a `prefers-reduced-motion`.
- Loader com duração mínima e limite máximo de segurança.
- Formulário de contacto com validação no lado do cliente.
- Botão de download do currículo em PDF.
- Navegação com suporte a acessibilidade.
- Fontes e assets servidos localmente.
- Favicon e Web App Manifest.

> O formulário de contacto realiza atualmente validação e simulação de sucesso. O envio real de mensagens será implementado numa futura versão com backend.
